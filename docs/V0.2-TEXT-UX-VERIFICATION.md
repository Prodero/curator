## Data and navigation details

- Open has an actual Bootstrap allocation, not the prepared task allocation. Its meter is labeled **Bootstrap** and reads returned `bootstrap.metrics.estimatedTokens` and `limits.budgetTokens`. When older data lacks limits, no budget is invented. Task allocation appears in Context Ready. Neither is the model's full context window or billing usage. Tokens are estimates; the 25-cell meter is quantized to approximately 4% per cell, with a rounded numeric percentage.
- Deferred questions and unapplied change **groups** use the existing review projection. The renderer does not count proposed groups as individual knowledge records or infer workflow-wide question counts from area counts.
- `entryActions` and `knowledgeRows` bind A–T to exact current record IDs, filters, page and project. `numberedActions` starts at 1 independently. Every response supplies fresh entry bindings, including an empty array outside a catalogue. Instructions prohibit using aliases from an older page/view/project, treating question input as navigation, or inferring IDs from titles. This is the existing agent-mediated dispatch contract, not a new hidden server-side keyboard dispatcher.
- Search is an input descriptor (`input.field=query`), not a fabricated search term. The agent collects the user's actual query before calling the existing tool. Layer filters, previous/next and Back are real bound read operations. Natural language requests remain valid. Numeric selection never grants approval.
- Healthy Prepare has no numbered action or approval prompt. View Context uses the context object returned by that Prepare; it must not call a new resolver or create another work session. Required omissions/conflicts/uncertain applicability and warnings remain visible; Core blocking remains authoritative.
- Framed text wraps by grapheme/display width. Full record and review bodies use a separately fenced, unframed verbatim fallback to retain code, indentation, long paths and complete wording. The fence grows beyond embedded backtick runs. ANSI/bidi controls are removed; no semantic body truncation is performed. A long verbatim line can scroll horizontally in the host.
- `plain:true` is an invocation-only ASCII frame/meter fallback. It neither changes preferences nor transliterates knowledge content. Color, fonts, animation, clicks and host wrapping are not assumed.

## Naming and compatibility

Curate Memory is used in shared text/App entry, continuation, start, result and instruction copy. Improve memory and Share knowledge remain distinct internal choices. Promotion prepares Versioned files; Curator does not commit or push. Existing `prodero_sync`, `prodero_memory_sync`, request/state IDs, persisted workflows, exact review bindings and recovery protections remain compatible. The former Sync Memory name is a legacy product label, not an API rename.

The text navigation contract changes from numeric table rows to letters. Generated managed instructions are updated together. A running host may retain cached instructions/tool descriptors until the user reconnects; no host restart or installed runtime change was performed here.
