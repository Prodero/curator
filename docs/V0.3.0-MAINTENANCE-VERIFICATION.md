## Delivered behavior

| Case | Result |
| --- | --- |
| Pending observation snapshots, exact duplicates, eligible existing deterministic consolidation | Existing synchronization runs automatically, with actual checkpoint/provenance receipts and retry/recovery. Active sessions are not closed to clear counters. |
| Eligible Local active Relevant inferred State/Lesson merge | The existing host agent proposes complete extractive clause coverage; deterministic checks require unchanged boundaries/priority/category and preserve source history. Metadata that the lifecycle create contract cannot preserve causes defer. |
| Supersession | Requires an existing canonical replacement edge, equal category/priority/applicability and no unsupported predecessor metadata. Timestamp or model assertion alone is insufficient. |
| Protected/Required/user/shared sources, unsupported scope refinement, incompatible claims, missing/incomplete/stale response | Original records stay current; the bounded attempt is deferred without a user moderation queue or fabricated answer/approval. |
| Actual task-relevant disputed records | A bounded read-only `task-dispute` evidence set reaches the current agent; it does not become ordinary selected context or editable knowledge. |
| Changed task/scope or missing current retrieval evidence | Previous proposal cannot mutate knowledge. Native task fingerprints and current-connection readiness are checked again. |
| Required-policy gap/conflict, incompatible schema/runtime, actual write/recovery failure | Existing blocker/error remains visible. The agent asks one concrete question only if the current task actually requires that unresolved intent. |
| Missing/incompatible Node or missing/broken npm | The setup guide discovers paths first without executing possible lazy-install shims, then proposes one approved preparation/Curator/MCP plan. Existing defaults/profiles/dev setups are preserved. |

The host protocol is `prodero_session_reconcile_prepare` / `prodero_session_reconcile_propose`; it is bound to the active prepared session and exact source revisions, with one reasoning attempt, bounded sources/bytes/time/retention, complete semantic validation, existing lifecycle transactions and exact replay. It uses the current host agent; no new model provider, credentials or external API is created.
